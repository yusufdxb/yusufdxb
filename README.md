## Selected systems

### HELIX

Self-healing runtime for ROS 2 robots that detects faults, holds the system safe, and coordinates recovery.

**8 live GO2 + Jetson sessions · 30 anomalies · 14 recovery actions**

`ROS 2 · C++`

[Code](https://github.com/yusufdxb/helix) · [Demo](https://youtu.be/PbKXB91-NSY)

### GO2-Phoenix

Sim-to-real locomotion with parity-gated deployment and fail-closed safety.

**32/32 simulated stand successes · ONNX deployment parity enforced**

`Isaac Lab · PPO · ONNX · ROS 2`

[Code](https://github.com/yusufdxb/go2-phoenix) · [Evidence](https://github.com/yusufdxb/go2-phoenix/blob/main/EVIDENCE.md) · [Demo](https://youtu.be/Nu0oWyJJbEM)

Failure-awareness study of a deployed driving model under distribution shift.

**1,159-frame parity-controlled reproduction · shifted inputs reveal silent internal failure**

`ONNX Runtime · CARLA · OOD detection`

[Code](https://github.com/yusufdxb/supercombo-blindspot) · [Demo](https://youtu.be/tnM18XGbNMY)
